## Default Permission

Allows the app to install APKs it downloaded, ask for the install permission, and open/uninstall the installed games (Android only; no-ops elsewhere).

#### This default permission set includes the following:

- `allow-can-install`
- `allow-open-install-settings`
- `allow-package-info`
- `allow-install`
- `allow-is-installed`
- `allow-launch`
- `allow-uninstall`
