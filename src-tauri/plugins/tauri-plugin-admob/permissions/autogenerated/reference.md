## Default Permission

Allows the app to initialize AdMob, show/hide the banner and load/show interstitials (Android only; no-ops elsewhere).

#### This default permission set includes the following:

- `allow-initialize`
- `allow-show-banner`
- `allow-hide-banner`
- `allow-load-interstitial`
- `allow-show-interstitial`
